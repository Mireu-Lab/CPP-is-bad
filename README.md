# 💻 CPP-is-bad

> **[📦 ARCHIVED]** 본 저장소는 대학교 C/C++ 프로그래밍 강의 실습 자료 및 알고리즘 구현 연습 목적의 아카이브 저장소입니다.

---

## 🎯 프로젝트 목적
- **과목명**: C/C++ 객체지향 프로그래밍 실습
- **목적**: C++ 기초 문법, 클래스 설계, 메모리 관리, 표준 템플릿 라이브러리(STL) 및 알고리즘 실습 과제 수행
- **브랜치 구성**:
  - `main`: 기초 C/C++ 실습 코드 및 빌드 스크립트
  - `homework`: 주차별 프로그래밍 실습 과제 모음
  - `lib`: 커스텀 유틸리티 및 데이터 처리 라이브러리 구현 연습
